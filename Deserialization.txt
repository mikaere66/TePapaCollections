
Deserializing different types in Android Kotlin, particularly from a format like JSON, often involves handling polymorphism. This means you might receive data that could represent one of several different classes, all inheriting from a common base or implementing a common interface. Kotlinx.Serialization is the recommended library for this.
Here's how to deserialize different types using Kotlinx.Serialization: Define a Sealed Class Hierarchy.
Create a sealed class as your base, and then define your different data types as subclasses of this sealed class. This clearly defines the possible types you expect.
Kotlin

    import kotlinx.serialization.Serializable
    import kotlinx.serialization.SerialName

    @Serializable
    sealed class BaseItem {
        abstract val id: String
    }

    @Serializable
    @SerialName("type_a") // This name will be used in the JSON to identify this subclass
    data class ItemA(
        override val id: String,
        val dataA: String
    ) : BaseItem()

    @Serializable
    @SerialName("type_b") // This name will be used in the JSON to identify this subclass
    data class ItemB(
        override val id: String,
        val dataB: Int
    ) : BaseItem()
Configure Json for Polymorphism.
When creating your Json instance, you need to tell it how to identify the different types. This is done using classDiscriminator. By default, it looks for a field named "type". If your JSON uses a different field name to distinguish types, you can specify it.
Kotlin

    import kotlinx.serialization.json.Json

    val json = Json {
        classDiscriminator = "item_type" // If your JSON uses "item_type" instead of "type"
        ignoreUnknownKeys = true // Optional: ignores fields not present in your data classes
    }
deserialize.
Now, you can deserialize your JSON string into a list or a single instance of your base sealed class. Kotlinx.Serialization will automatically use the classDiscriminator and @SerialName annotations to determine the correct subclass to deserialize into.
Kotlin

    val jsonString = """
        [
            { "item_type": "type_a", "id": "1", "dataA": "Hello" },
            { "item_type": "type_b", "id": "2", "dataB": 123 }
        ]
    """

    val items: List<BaseItem> = json.decodeFromString(jsonString)

    // You can then check the type and cast if needed
    items.forEach { item ->
        when (item) {
            is ItemA -> println("Item A: ${item.dataA}")
            is ItemB -> println("Item B: ${item.dataB}")
        }
    }
Key Points:
@Serializable: Annotate all classes involved in serialization/deserialization.
@SerialName: Use this on subclasses to explicitly define the string value in the JSON that identifies that specific type.
classDiscriminator: Configure this in your Json instance to specify the JSON field that holds the type identifier.
Sealed Classes: Provide a strong, type-safe way to represent a fixed set of possible types.
This approach allows you to handle varied data structures within a single deserialization process, maintaining type safety and clarity in your code.
